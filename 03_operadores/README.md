# Filtering Operators

This section contains exercises using SQL operators to create more specific filters.

## Objective

The objective is to learn different ways of filtering data without having to write multiple conditions separately.

## Exercises

### Exercise 1 — IN

**Task:**
Retrieve products whose category belongs to a specific list of categories.

**Objective:**
Practice using `IN` to compare a column against multiple possible values.

### Exercise 2 — BETWEEN

**Task:**
Retrieve products whose price falls within a specified range.

**Objective:**
Understand how `BETWEEN` can be used to filter values within a range.

### Exercise 3 — LIKE

**Task:**
Retrieve records based on a text pattern.

**Objective:**
Practice searching for partial text matches using `LIKE`.

### What I practiced

* `IN`
* `BETWEEN`
* `LIKE`
* Text pattern matching
* Range filtering
* Multiple-value filtering
