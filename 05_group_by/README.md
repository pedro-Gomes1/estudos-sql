# GROUP BY

This section contains exercises focused on grouping records based on common values.

## Objective

The objective is to understand how `GROUP BY` allows aggregate functions to be applied to groups of records instead of the entire table.

## Exercises

### Exercise 1 — Group products by category

**Task:**
Group products according to their category.

**Objective:**
Understand how SQL creates groups based on the values of a column.

### Exercise 2 — Aggregate data by category

**Task:**
Calculate aggregate values for each product category.

**Objective:**
Practice combining `GROUP BY` with aggregate functions.

### What I practiced

* `GROUP BY`
* Grouping records
* Combining `GROUP BY` with aggregate functions
* Aggregating data by category
