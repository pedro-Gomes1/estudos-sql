# COALESCE

This section contains exercises focused on handling `NULL` values using `COALESCE()`.

## Objective

The objective is to understand how missing values can affect query results and how `COALESCE()` can be used to provide a default value.

## Exercises

### Exercise 1 — Replace NULL values

**Task:**
Return the value of the `desconto` column, replacing `NULL` with `0`.

**Objective:**
Practice handling missing values and producing a more useful result for analysis.

### Exercise 2 — COALESCE with SUM

**Task:**
Calculate the total value associated with each customer and return `0` when there are no matching records.

**Objective:**
Understand how `COALESCE()` can be combined with aggregate functions to handle groups without matching records.

### What I practiced

* `NULL`
* `COALESCE()`
* `SUM()`
* Handling missing values
* Combining functions
