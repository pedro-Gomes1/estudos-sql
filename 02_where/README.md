# WHERE

This section contains exercises focused on filtering records using the `WHERE` clause.

## Objective

The objective is to learn how to retrieve only the records that satisfy specific conditions.

## Exercises

### Exercise 1 — Filtering records

**Task:**
Retrieve products that meet a specific condition.

**Objective:**
Understand how `WHERE` restricts the records returned by a query.

### Exercise 2 — Multiple conditions

**Task:**
Filter products using more than one condition with `AND` and `OR`.

**Objective:**
Practice combining conditions to create more specific queries.

### What I practiced

* `WHERE`
* `AND`
* `OR`
* Comparison operators
* Combining multiple conditions
