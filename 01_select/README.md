# SELECT

This section contains exercises focused on retrieving data from a database using the `SELECT` statement.

## Objective

The objective of these exercises is to understand how to retrieve specific columns and records from database tables.

## Exercises

### Exercise 1 — Selecting columns

**Task:**
Retrieve specific columns from the `produtos` table.

**Objective:**
Practice selecting only the information required from a table instead of retrieving all available columns.

### What I practiced

* `SELECT`
* Selecting specific columns
* Understanding table structure
* Basic data retrieval
