# Aggregate Functions

This section contains exercises using SQL aggregate functions to summarize data.

## Objective

The objective is to learn how to transform multiple records into useful summary information.

## Exercises

### Exercise 1 — COUNT

**Task:**
Count the number of records in the table.

**Objective:**
Understand how `COUNT()` can be used to determine the number of records.

### Exercise 2 — SUM

**Task:**
Calculate the total value of a numeric column.

**Objective:**
Practice calculating totals from stored data.

### Exercise 3 — AVG

**Task:**
Calculate the average value of a column.

**Objective:**
Understand how `AVG()` can be used to obtain an average from multiple records.

### Exercise 4 — MAX and MIN

**Task:**
Identify the highest and lowest values in a column.

**Objective:**
Practice extracting extreme values from a dataset.

### What I practiced

* `COUNT()`
* `SUM()`
* `AVG()`
* `MAX()`
* `MIN()`
* Data summarization
