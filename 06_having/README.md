# HAVING

This section contains exercises focused on filtering grouped results using the `HAVING` clause.

## Objective

The objective is to understand how `HAVING` works together with `GROUP BY` to filter groups based on aggregate calculations.

## Exercises

### Exercise 1 — Filter groups by COUNT

**Task:**
Return categories that contain more than a specified number of products.

**Objective:**
Practice filtering groups based on the number of records.

### Exercise 2 — Filter groups by AVG

**Task:**
Return categories whose average product price is greater than a specified value.

**Objective:**
Practice filtering grouped data using an aggregate calculation.

### Exercise 3 — Filter groups by SUM

**Task:**
Return categories whose total value satisfies a specified condition.

**Objective:**
Practice using `HAVING` with `SUM()`.

### What I practiced

* `HAVING`
* `GROUP BY`
* `COUNT()`
* `AVG()`
* `SUM()`
* Difference between `WHERE` and `HAVING`
